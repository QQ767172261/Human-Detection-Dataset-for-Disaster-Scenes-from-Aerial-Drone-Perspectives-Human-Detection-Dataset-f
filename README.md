### 应用价值
面向灾害应急搜救场景，包含烟雾、洪水、废墟、车祸等复杂干扰背景，覆盖多种人体姿态，解决灾后远距离、低辨识度下人体识别难题；用于训练无人机搜救检测模型，提升模型在灾害复杂环境下的鲁棒性，辅助应急救援人员快速定位幸存者，支撑应急救灾AI系统落地。
